# HTML-Tag-Generator

Скрипт, который по нажатию кнопки создаёт готовый HTML-код (например, для вставки ссылки или картинки). Идеален для контент-менеджеров, блогеров и верстальщиков, которым нужно быстро получить чистый тег без ручного написания.

## Как это работает

1. Пользователь выбирает тип тега (ссылка `<a>` или картинка `<img>`).
2. Заполняет поля (URL, текст, alt, размеры).
3. Нажимает кнопку «Сгенерировать».
4. Готовый код копируется в буфер обмена одной кнопкой.
