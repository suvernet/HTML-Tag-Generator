
# HTML Tag Generator

Мини-утилита на чистом JavaScript для быстрой генерации HTML-разметки.

## Возможности

- Генерация тегов `div`, `img`, `a`, `p`, `span` с нужными атрибутами.
- Вывод результата через запятую, пробел или с переносом строки.
- Работает без установки и зависимостей.

## Быстрый старт

1. Скачайте репозиторий или откройте `index.html` в браузере.
2. Введите названия тегов и параметры.
3. Нажмите «Сгенерировать» и скопируйте готовый код.

## Примеры использования

- Галерея из картинок с подписями.
- Карточки товаров с кнопкой.
- Разметка для вставки в WordPress или конструктор сайтов.
